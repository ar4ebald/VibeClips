# Vibe Clips

Расширение для Chrome и Firefox: клипы из стримов и видео YouTube за несколько секунд.
Выберите начало и конец ползунком под плеером — и скачайте MP4 в исходном качестве (до 1080p),
без записи экрана, без проигрывания и без сервера.

- [`extension-chrome`](extension-chrome) — версия для Chrome и Edge. Там же описано, как всё устроено.
- [`extension-firefox`](extension-firefox) — та же версия для Firefox 140+.

## Возможности

- Список трансляций канала по значку расширения (по умолчанию [@Vibe_Quuenn](https://www.youtube.com/@Vibe_Quuenn)).
- Панель клипа под плеером на любом видео YouTube: кнопка ✂ рядом с шестерёнкой.
- Клип собирается из кусков, которые плеер YouTube и так скачивает, — без пережатия, с точностью до кадра.
- Эфиры: и с перемоткой (последние ~12 часов), и без неё (то, что загрузилось после открытия страницы).
