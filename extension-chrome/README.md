# Vibe Clips — клипы со стримов YouTube

Расширение для Chrome и Edge. Работает само по себе: без сервера, без ключей и без проигрывания
клипа в реальном времени. Клип скачивается в MP4 в исходном качестве (до 1080p) за несколько секунд.

## Установка (один раз)

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. Включите **Режим разработчика** (переключатель справа вверху).
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку `extension-chrome`.
4. Закрепите значок ✂ на панели Chrome (значок пазла → булавка у «Vibe Clips»).
5. Обновите уже открытые вкладки YouTube (F5) — расширение подключается при загрузке страницы.

## Как сделать клип

1. Нажмите значок ✂ на панели Chrome — откроется список трансляций канала (по умолчанию `@Vibe_Quuenn`,
   канал можно сменить в поле сверху).
2. Нажмите на стрим — он откроется на YouTube, и под плеером сразу появится панель «Клип».
   На любом другом видео панель открывается кнопкой ✂ в плеере YouTube (рядом с шестерёнкой).
3. Выберите отрезок: перетащите розовую и фиолетовую ручки, впишите время в поля или нажимайте
   «⇤ Отсюда» и «Досюда ⇥» во время просмотра. «Приблизить» растягивает шкалу вокруг фрагмента.
4. Нажмите **Скачать клип**. Плеер сам перемотается и догрузит нужный кусок, MP4 сохранится в «Загрузки»,
   а видео вернётся туда, где вы были.

## Как это устроено

Плеер YouTube скачивает видео кусками. Расширение перехватывает эти куски и складывает
нужные кадры в MP4 без пережатия, поэтому качество исходное, а начало и конец точны до кадра.
Чтобы куски можно было склеить в обычный MP4, расширение просит YouTube отдавать видео в H.264.
Из-за этого, пока расширение включено, YouTube показывает видео максимум в 1080p
(4K и 1440p приходят только в других форматах). Для просмотра в 4K расширение можно временно выключить.

Если YouTube на паузе не догружает видео, расширение включает воспроизведение без звука на скорости 2×,
пока нужный кусок не загрузится, а потом возвращает всё как было.

В памяти вкладки хранится до ~300 МБ последнего загруженного видео (это примерно 10 минут 1080p).

В трансляциях, где автор отключил перемотку, YouTube отдаёт только живой эфир, поэтому клип можно сделать
лишь из того, что загрузилось после открытия страницы (до ~10 минут назад). Полоса в панели показывает
именно этот кусок, а выделение само идёт за эфиром — последние 30 секунд, — пока вы его не поправите.

## Разрешения

- `youtube.com` — работать на страницах YouTube и загружать список трансляций.
- `storage` — запомнить выбранный канал.
- `declarativeNetRequestWithHostAccess` — API YouTube не отвечает на запросы с адресом расширения,
  поэтому для запросов списка подставляется адрес youtube.com.

Расширение ничего никуда не отправляет: клип собирается и сохраняется прямо в браузере.
